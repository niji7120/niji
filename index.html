    형식 선택
    ※ 단식은 2·4·8·16명 권장
    복식 팀 구성 방법
    선택된 선수 순서(위→아래)로 자동 팀을 구성해요.
    1번↔마지막, 2번↔끝에서 2번 방식으로 짝이 맺어져요.
    선수를 순서대로 2명씩 클릭하면 팀이 만들어져요. 파란색 = 1번째, 초록색 = 2번째(파트너)
    상대팀 배치 방법
    선수 순서(위→아래)대로 자동으로 대진이 짜여요.
    시드 순서를 조정하고 싶다면 선수 목록 순서를 바꿔서 생성하세요.
    선수를 2명씩 클릭해서 1라운드 대진을 직접 짜세요.
    파란색 = A팀, 초록색 = B팀(상대)
    참가 선수
    📖 사용 설명서
    👤 1. 프로필
    상단 사진 영역을 탭하면 프로필 사진을 등록할 수 있어요
    이름·클럽·나이대·손잡이·구력·스타일 항목을 탭하면 바로 수정되고 자동 저장됩니다
    라켓은 기본 2자루, "라켓 추가" 버튼으로 3자루까지 등록할 수 있어요. RACQUET 1·2·3 항목을 탭해서 펼친 뒤 라켓명·스트링·텐션·교체일을 입력하세요
    스트링 선택 — 과거에 입력한 스트링 목록에서 고르거나, 아래 입력창에 직접 타이핑할 수 있어요. 드롭다운에서 선택하면 입력창에도 자동으로 채워져요
    스트링 교체일을 입력하면 배너에 D+일수와 교체 후 게임 수가 자동 표시돼요 — 🟢 양호(30일 이내) / 🟡 주의(31~90일) / 🔴 교체 권장(90일 초과)
    프로필 하단에서 🎾 테니스 / 🏸 배드민턴 / 🏓 피클볼 종목을 설정하세요. 경기기록·통계 탭의 [종목 변경 →] 버튼으로도 바로 이동해요
    상단 🌙/☀️ 버튼으로 다크/라이트 테마를 전환할 수 있어요
    🎾 2. 경기 기록
    앱을 열면 날짜가 오늘로 자동 입력됩니다. 과거 날짜로 바꿀 수도 있어요
    단식 / 복식을 선택하세요. 복식이면 파트너·상대2 입력란이 추가됩니다
    날짜 · 상대 이름 · 결과(승/패)는 필수, 스코어·메모·사용 라켓은 선택 사항이에요
    이름 입력 시 초성 자동완성을 지원해요. 예: 'ㄱㄷㅎ' → '김동현' 자동 추천
    경기 입력 시 사용 라켓을 선택하면 라켓별 게임 수가 따로 카운트돼요
    오늘 경기는 상단에 바로 표시되고, 이전 경기는 📋 이전 경기 기록을 탭해서 확인하세요
    저장된 경기는 ✏️ 수정 · 🗑️ 삭제가 가능해요
    🏆 대회에서 입력한 스코어는 경기기록에 자동 반영됩니다
    경기 카드 오른쪽 📤 공유 버튼을 탭하면 결과 공유 팝업이 열려요 — 카카오톡·문자·밴드 등 폰 기본 공유창으로 자랑하거나, 텍스트 복사 후 붙여넣기 할 수 있어요
    📊 3. 통계
    통계 탭 상단에 현재 선택된 종목이 표시됩니다. [종목 변경 →] 버튼을 누르면 프로필 탭에서 종목을 바꿀 수 있어요
    연승·연패 배너 — 현재 연속 기록이 자동으로 표시됩니다
    상세 요약 — 이번 달 성적, 단식·복식 승률, 가장 많이 이긴 상대·가장 어려운 상대
    월별 승률 그래프 — 최근 6개월 성적 추이를 바 차트로 확인
    상대 전적 · 파트너 궁합 · 상대팀 상성을 각각 분석해줘요. 기본 상위 5명만 표시되고, [더보기] 버튼으로 전체를 볼 수 있어요
    각 섹션 상단 🔍 검색창에서 이름 또는 초성으로 바로 찾을 수 있어요
    각 항목은 탭하면 펼쳐지는 아코디언 방식으로 필요한 것만 열어볼 수 있어요
    👥 4. 선수 관리
    선수 등록 시 성별·등급·나이대·손잡이·구력·플레이스타일을 함께 입력할 수 있어요
    이름 입력 시 초성 검색을 지원해요. 예: 'ㄱㄷㅎ' 입력 → '김동현' 검색
    클럽 관리에서 클럽을 만들고 선수에게 배정할 수 있어요. 한 선수가 여러 클럽에 속할 수도 있어요
    선수 이름을 탭하면 상세 전적 페이지로 이동해요 — 나와의 전적·승률·최근 대전 기록 확인 가능
    이름순·최근 대전순·전적 많은 순·승률 높은 순으로 정렬할 수 있어요
    📝 메모 버튼으로 선수별 특징이나 스타일을 기록해두세요
    🏆 5. 대회
    대회 탭에는 🔄 한울방식 · 🏆 토너먼트 · 🎾 스코어 세 가지 메뉴가 있어요
    🔄 한울방식 — 매 게임마다 파트너와 상대가 자동으로 바뀌는 순환 복식 대회예요. 참가 인원과 게임 수를 설정하면 모든 조합이 자동으로 짜여요. 예) 8명·4게임이면 모두 골고루 파트너/상대로 만나요
    한울방식 화면 상단의 대진표 / 순위표 탭을 눌러 전환할 수 있어요. 순위표는 승·패·득점을 반영한 승점 순으로 자동 정렬돼요
    🏆 토너먼트 — 단식·복식 KO방식 대진표예요. 이긴 팀만 다음 라운드로 진출하고, 결과 입력 시 다음 경기가 자동으로 채워져요
    복식 파트너 구성 — 선수 선택 후 아래 두 가지 중 선택해요
    · 🎲 자동 팀 섞기: 선수 순서대로 1번↔마지막, 2번↔끝에서 2번 방식으로 자동 짝을 맺어요
    · ✋ 직접 파트너 지정: 선수를 2명씩 직접 클릭해서 팀을 만들어요
    상대팀 배치 방법 — 1라운드 대진을 어떻게 짤지 선택해요
    · 🎲 자동 배치: 선수/팀 순서대로 표준 시드 방식으로 자동 대진이 만들어져요
    · ✋ 직접 대진 지정: 내가 원하는 대로 누가 누구와 1라운드에서 붙을지 직접 클릭해서 대진을 짜요
    준결승 패자는 자동으로 3·4위전에 배치됩니다
    토너먼트 화면에서 🪜 대진표(사다리 보기)와 📋 경기 목록(카드 보기) 두 가지 방식으로 전환해서 볼 수 있어요
    결승 결과가 입력되면 🥇 우승 · 🥈 준우승 · 🥉 3위가 시상대 형태로 자동 표시돼요
    선수 탭에서 등록한 선수를 바로 불러오거나, 직접 이름을 입력할 수 있어요
    대회에서 입력한 스코어는 경기기록에 자동 반영됩니다
    📊 스코어보드 — 실제 경기 진행 중 실시간 점수판이에요. 폰을 가로로 돌리면 대형 점수 화면이 열려요
    스코어보드에서 +POINT로 점수 추가, ACE·FAULT(더블폴트) 버튼으로 특수 상황 입력, ↩ UNDO로 되돌리기 가능해요
    40-40 상황에서 자동으로 DEUCE → AD 처리되며, 🔀 타이브레이크 버튼으로 타이브레이크를 시작할 수 있어요
    하단 SETUP 탭에서 선수 이름과 경기 제목을 직접 입력할 수 있어요
    🎾 스코어 버튼은 한울방식·토너먼트 설정 없이 바로 스코어보드만 빠르게 열고 싶을 때 사용해요. 친선경기나 즉석 게임 점수 기록에 편리해요
    🎾 6. 스트링 관리
    프로필 탭 → 라켓 카드에서 스트링명을 입력하세요. 과거에 입력한 스트링은 드롭다운에서 바로 선택할 수 있어요
    스트링 교체일을 입력하면 프로필 배너에 D+일수와 교체 후 게임 수가 자동 표시됩니다
    배너 색상으로 교체 시기를 한눈에 확인할 수 있어요 — 🟢 양호(30일 이내) / 🟡 주의(31~90일) / 🔴 교체 권장(90일 초과)
    경기 입력 시 사용 라켓을 선택하면 라켓별 게임 수를 따로 카운트해줘요
    스트링 선택이 안 보여요 — 스트링 입력 기록이 없으면 직접 입력창만 표시돼요. 기록이 쌓이면 드롭다운이 자동으로 나타납니다
    스트링 관리 탭 상단 🛠️ 교체 인증하기 버튼을 탭하면, 라켓·스트링·텐션·교체일 정보가 자동으로 문구로 만들어져서 카카오톡 등으로 바로 공유할 수 있어요
    알림은 이제 날짜와 게임 수를 함께 봐요. 라켓 카드의 게임 임계치를 넘게 치면, 아직 교체일이 안 됐어도 주의/교체 알림이 떠요
    🔀 하이브리드 체크박스를 켜면 메인·크로스 스트링을 따로 기록할 수 있어요
    📅 캘린더에 알림 등록 버튼을 누르면 다음 교체 예정일이 폰 캘린더 앱에 알림으로 저장돼요 — 앱을 안 켜도 알림이 와요
    라켓 카드 아래 ➕ 라켓 추가 버튼으로 라켓 3까지 등록할 수 있고, 저장할 때 교체 사유·비용도 함께 남길 수 있어요
    🎯 7. 전술판
    대회 탭 상단의 📋 전술판 버튼을 탭하면 전용 화면이 열려요
    코트에서 선수(원형 아이콘)를 드래그해서 위치를 자유롭게 움직일 수 있어요
    선수를 한 번 탭하면 타구각 표시, 두 번 탭하면 이름·번호·포지션·색상을 편집할 수 있어요
    상단 버튼으로 기본·양쪽전위·양쪽후위·I포메이션·호주 5가지 대형을 바로 적용할 수 있어요
    ☰ 버튼(화면 오른쪽 가운데)을 탭하면 조작 버튼이 나타나요
    ➡️ 화살표 — 선수 탭 후 드래그: 이동 화살표 / 빈 곳 드래그: 자유 화살표
    ✏️ 그리기 — 손가락으로 코트 위에 자유롭게 선을 그을 수 있어요
    ⭕ 커버존 / 🎾 공 / 📐 타구각 — 각각 탭해서 표시/숨기기 전환
    🎨 보드설정 — 코트 색상(그린·클레이·하드·다크·잔디), 그리기 색상 변경
    💾 저장 / 📂 불러오기 — 전술판 배치를 이름 붙여 저장하고 나중에 다시 불러올 수 있어요 (최대 20개)
    🔗 공유 — 현재 전술판을 URL 링크로 만들어 카카오톡 등으로 공유할 수 있어요
    🗑️ 삭제는 화살표·그리기만 지워요. 🔄 초기화는 선수 위치까지 원래대로 돌아가요
    🔗 8. 공유 & 백업
    데이터는 클라우드(Firebase)에 자동 저장됩니다. 폰을 바꿔도 같은 구글 계정으로 로그인하면 그대로 유지돼요
    💾 데이터 내보내기 — 모든 기록을 JSON 파일로 저장해 추가 백업할 수 있어요
    📂 가져오기 — 백업한 JSON 파일을 불러와 데이터를 복원할 수 있어요
    🧹 저장공간 정리 — 기기 캐시만 삭제돼요. 클라우드 데이터는 안전하게 유지됩니다
    💬 카카오 오픈채팅 — 공유 탭에서 참여해 동호인들과 소통하세요
    ⚠️ 9. 자주 묻는 질문
